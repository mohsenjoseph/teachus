# چک‌لیست آماده‌سازی هاست

## اطلاعات فعلی
- PHP وب: 8.3
- دیتابیس: MySQL
- فضای دیسک: حدود ۵ تا ۱۰ گیگابایت
- نوع میزبانی: اشتراکی
- Cron Job: در دسترس
- Terminal/SSH: در دسترس نیست
- مسیر نمونه PHP CLI اعلام‌شده: `/usr/local/bin/php` (هنوز باید با اجرای واقعی تأیید شود)

## مواردی که باید بررسی شوند
- نسخه PHP CLI دقیقاً 8.3 باشد.
- افزونه‌های `pdo_mysql`, `mbstring`, `intl`, `curl`, `openssl`, `json`, `xml`, `dom`, `fileinfo`, `gd`, `zip`, `bcmath`, `tokenizer`, `iconv` فعال باشند.
- اتصال خروجی HTTPS به APIهای موردنیاز مجاز باشد.
- محدودیت زمان و حافظه Cron مشخص باشد.
- امکان نوشتن فایل در مسیر خصوصی خارج از `public_html` وجود داشته باشد.
- نسخه MySQL و پشتیبانی InnoDB و utf8mb4 مشخص باشد.
- محدودیت حجم فایل، inode و فضای backup مشخص باشد.

## نمونه دستور بررسی CLI
پس از تأیید مسیر توسط میزبان:
```bash
/usr/local/bin/php -v
```

## هشدار
تا پیش از دریافت اطلاعات قطعی، مسیر PHP CLI، محدودیت منابع و دسترسی شبکه را قطعی فرض نکنید.
