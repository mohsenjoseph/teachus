# TeachUs | مسیر رشد من

پلتفرم رشد و مهارت‌آموزی کودکان ۷ تا ۱۲ سال با تمرکز بر آموزش مهارت‌های ضروری زندگی، تجربه عملی و همراهی والدین.

**دامنه:** https://teachus.ir  
**نام پلتفرم:** TeachUs  
**نام محصول:** مسیر رشد من

## هدف محصول
کمک به کودکان برای شناخت بهتر خود، یادگیری مهارت‌های ضروری و تجربه توانایی‌ها از طریق درس‌های کوتاه، فعالیت‌های عملی و بازخورد قابل فهم.

## گروه‌های سنی
- ۷ تا ۹ سال: محتوای تصویری، ساده، بازی‌محور و مناسب همراهی والد.
- ۱۰ تا ۱۲ سال: چالش، تصمیم‌گیری، تحلیل و استقلال بیشتر.

## حوزه‌های مهارتی نسخه اولیه
1. استقلال فردی
2. تفکر و حل مسئله
3. سواد دیجیتال
4. سواد مالی

## چرخه تجربه کودک
حساب والد ← پروفایل کودک ← شناخت علایق ساده ← انتخاب مسیر ← درس کوتاه ← مأموریت عملی ← ثبت نتیجه و مشاهده پیشرفت.

## فناوری‌ها
- PHP 8.3
- Yii2 Advanced
- MySQL / InnoDB
- HTML، CSS، JavaScript و Bootstrap
- Cron Job و صف وظایف مبتنی بر MySQL
- اتصال کنترل‌شده به سرویس‌های تولید متن، تصویر و گفتار

## سیاست تولید و انتشار محتوا
هدف عملیاتی اولیه، آماده‌سازی روزانه دو بسته آموزشی کامل است. هر بسته می‌تواند شامل درس، تصویر، آزمون، مأموریت عملی و صوت درس باشد. هیچ بسته‌ای بدون تأیید صریح مدیر منتشر نمی‌شود.

## وضعیت توسعه
این مخزن در مرحله آماده‌سازی فنی و مستندسازی است. کد اجرایی Yii2، Migrationها و اتصال سرویس‌ها در مراحل بعدی اضافه می‌شوند.

## امنیت
- هیچ رمز عبور، کلید API، توکن، فایل تنظیمات محرمانه یا اطلاعات کاربران را در Git ثبت نکنید.
- فایل `.env` و تنظیمات محلی باید خارج از کنترل نسخه باشند.
- داده‌های کودکان باید حداقلی، خصوصی و تحت کنترل والد نگهداری شوند.
- محتوای تولیدشده تا زمان تأیید باید در فضای خصوصی باقی بماند.
